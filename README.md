# Z-MORE Updates

Public APK downloads for the unofficial Z-MORE Zeekr 7X companion app.

## อัปเดตจากในแอป

ติดตั้ง APK จากหน้า Releases หนึ่งครั้ง จากนั้นเข้า **ตั้งค่า → ตรวจสอบอัปเดต** เพื่อดาวน์โหลดรุ่นถัดไป
Android จะให้ยืนยันการติดตั้ง และอาจขออนุญาตติดตั้งแอปจากแหล่งนี้

## In-app updates

Install the APK from Releases once, then use **Settings → Check for updates**.
The car does not need a GitHub account. Confirm installation in Android when prompted.

Each release includes the APK, SHA-256 checksum, license and attribution notices.
This repository is a download channel; it does not change the privacy of the source repository.

Z-MORE is unofficial experimental software. Vehicle-specific features need a parked-car test.
